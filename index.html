Ensemble Knowledge Distillation

Problem

Complex ensemble models achieve high accuracy but are too heavy for real-time edge deployment in resource-constrained environments.

Stack & Architecture

Implemented using Python, Scikit-learn, and PyTorch. We trained a large ensemble of models (Random Forest, XGBoost) and used knowledge distillation to transfer their predictive power into a single, lightweight neural network.

Results

Reduced model size by 85% while maintaining 97% of the original ensemble's accuracy, enabling real-time inference on low-power devices.

Algorithmic Trading Bot

Problem

Financial markets are highly volatile. Retail traders often struggle to remove emotion from their trading decisions, leading to poor risk management and inconsistent returns.

Stack & Architecture

Currently in development using Python. The system leverages Bayesian probability for signal generation and Expected Value (EV) filtering. Position sizing is calculated mathematically using the Half-Kelly criterion to optimize risk-adjusted returns.

Current Status

Actively working on this project. The backtesting engine and signal generation algorithms are complete. Currently integrating live exchange APIs and building a monitoring dashboard.
